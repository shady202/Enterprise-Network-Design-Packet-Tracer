# Introduction to Networking Coursework

A polished showcase of networking coursework materials, including the original assignment brief and Packet Tracer project files.

## Overview

This repository contains supporting files for an Introduction to Networking coursework submission. It is intended to document and preserve the project assets in a clean, professional format.

## Contents

- `Networking Group assignment.docx` — assignment brief / coursework document
- `Group IN Assignment (5).pkt` — Cisco Packet Tracer network simulation project
- `README.md` — repository overview and usage notes

## Getting Started

1. Open the assignment brief to review the project requirements.
2. Open the `.pkt` file in [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer) to inspect or run the network topology.
3. Review the simulation, device configuration, and network design choices used in the coursework.

## Requirements

- [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer) for the `.pkt` file
- A word processor such as Microsoft Word or LibreOffice Writer for the `.docx` file
